# Nouvelle Vis

## Architecture
```
nouvelle_vis/
├── index.html      ← accueil
├── stock.html      ← stock disponible + bandeau des arrivages
├── panier.html     ← panier + réservation
├── css/style.css
├── js/
│   ├── data.js     ← config (nom, dates d'arrivage, adresse) + produits
│   └── app.js      ← logique (header/footer, panier, filtres)
└── img/            ← photos des produits et de l'accueil (référencées dans data.js et index.html)
```
